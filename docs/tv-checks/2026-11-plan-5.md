# TV check: plan 5 (packaging for other people)

- **Date:** 23 November 2026
- **TV:** LG C9, webOS 4.5, rooted with Homebrew Channel
- **Package:** 1.0.0, made with `node scripts/release.mjs --base-url http://<PC address>:8080` and served
  from Simon's PC with `npx http-server dist/release -p 8080`
- **Tried by:** Simon, who reported the results in conversation.

## Result

- Homebrew Channel read the repository index, listed Home Assist LG, accepted the manifest's size and
  checksum, installed the package over the 0.4.0 one, and launched it. Simon: "All looks great."
- The icon did not show, as expected: it was still fetched from GitHub, and the repository is private.
  The local test now serves the icon itself.

## Lessons for the guide

- Simon first used the example address `192.168.1.10` from the instructions rather than his PC's own
  address, and nothing could connect. The release guide now says how to find the address, and the
  examples use `<address>`.
- On a fresh clone, `npm install` must run before `npm run package`.
- The developer-mode route (webOS Dev Manager) was not tried: the C9 is rooted, and the Developer Mode
  app must not be reinstalled on a rooted TV.
